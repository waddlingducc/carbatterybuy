# carbatterybuy.net — GitHub Pages static website

Upload the CONTENTS of this folder to your GitHub repository (index.html must be at the repository root).
In repository Settings → Pages, choose Deploy from a branch, select your branch and / (root), then Save.

No npm install or build step is needed. The site supports both a repository URL
(https://USERNAME.github.io/REPOSITORY/) and a root/custom-domain URL.
All article and archive directories contain index.html so direct links and refreshes work.
The homepage browser tab reads: Home - Car Battery Buy.

This archive contains 87 articles, 4 source pages, local images, fonts and the battery favicon.
Ads and Google tags are excluded. Search, navigation and the article content work in the browser.

IMPORTANT: GitHub Pages cannot run the original contact/comment backend. Those forms
are replaced with clear unavailable notices; no messages are sent or silently discarded.
There is no admin dashboard or database in this archive.
No custom domain is configured automatically. Only connect carbatterybuy.net after
configuring that domain in GitHub Pages and its DNS.

To view locally, run python3 -m http.server 8000 in this folder, then open http://localhost:8000.
Do not double-click index.html: the site loads its content over HTTP.
